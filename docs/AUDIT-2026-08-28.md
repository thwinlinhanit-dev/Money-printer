## CRITICAL

### C-1. Recovery path silently destroys recorded data â€” `core/src/log.rs:212-213`
The header-length check is off by two. The on-disk header is
`MAGIC(8) + FORMAT_VER:u16(2)` = **10 bytes** (written at `log.rs:229-230`;
`scan_valid_len` correctly returns 10 for a header-only file at `log.rs:155`),
but `open()` computed `header_len = (MAGIC.len() + 4)` = 12, so a header-only
file was judged headerless and open() appended a **second header**. The next
session's `scan_valid_len` read the second header as a frame: length field
`0x474F4C50` â‰ˆ 1.19 GB > `MAX_FRAME_LEN` â†’ `Torn` â†’ `valid = 10` â†’
`set_len(10)` truncated away every event recorded since the duplicate. Silent,
unrecoverable, reported `Ok`. Violates W-6 via the code meant to protect it.

**Fix:** header length = `MAGIC.len() + 2`; regression test opens a
header-only log, appends frames, reopens, and asserts the frames survive.

### C-2. `prune` green-lights deleting raw logs with uncompacted tails â€” `storage/src/prune.rs:29-64`
`verify_prunable` checked only manifest existence, Parquet existence, and
`rows == manifest.events`. It never compared the raw log against the Parquet
footer's `source_log_hash` (`parquet_trades.rs:23`, KV `STO-8` â€” recorded
precisely for this). Scenario: compact a day â†’ late venue data appends to the
raw log â†’ stale manifest still matches stale Parquet â†’ human deletes raw log â†’
appended events unrecoverable.

**Fix:** verify `footer.source_log_hash == hash(raw logs for venue/date)` and
refuse when the raw log's mtime is newer than the Parquet's.

### C-3. Allocator is fail-OPEN on NaN â€” `risk/src/allocator.rs:46-51`
`f64::clamp` propagates NaN and `NaN.min(cap)` returns **cap**:
```rust
let capped = raw.min(i.kelly_cap.max(0.0));   // NaN.min(cap) == cap
let w = if capped.is_finite() { capped } else { 0.0 };  // too late
```
A NaN `regime_fit`/`corr_penalty`/`dd_gov` from a corrupt feature pipeline
assigned that strategy its **maximum** weight, and the renormalizer scaled
everyone else down to pay for it. The existing proptest only generated finite
inputs, so it could not catch this.

**Fix:** `if raw.is_finite() { raw.min(...) } else { 0.0 }` + proptest over
`f64::ANY` (NaN included) asserting weight 0.

## HIGH

  `risk/src/killswitch.rs:18`, `gate.rs:254`): `latch.rs` documented that the
