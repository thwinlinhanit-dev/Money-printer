## Verdict (pre-fix)

The scaffolding — determinism discipline, net-of-fees accounting, gate shape,
one-way kill switches, guardrail CI, spec honesty — is trustworthy to build on.
But pre-fix the system would **flatter any strategy** run through it: the only
shipped strategy traded the wrong signal (CVD-as-funding, dead stop), NaN
intents walked through the risk gate to a fill, and the Binance book feeding it
could desync forever without detection. All Critical/High findings are fixed
in-tree with tests; the remainder are honestly-tracked draft-spec work or
owner-gated items.
